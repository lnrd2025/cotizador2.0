# Cotizador de Criptomonedas

Aplicación web interactiva desarrollada en JavaScript que permite calcular el monto equivalente de criptomonedas a comprar según la divisa seleccionada (USD, EUR, VES), consumiendo la API pública en tiempo real de Binance.

## Características

- Consulta de datos en tiempo real mediante `fetch` asíncrono.
- Soporte para conversión dinámica a Bolívares (VES) mediante par de referencia USDT/VES.
- Muestra el precio actual, el más alto, el más bajo y la variación de las últimas 24 horas.
- Interfaz moderna, responsiva y ligera construida con CSS puro.

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la interfaz.
- **CSS3**: Estilos adaptativos e interfaz visual personalizada.
- **JavaScript (ES6+)**: Manipulación del DOM, eventos e integración de API asíncrona (`async/await`).
- **Binance REST API**: Fuente de información del mercado de criptoactivos.
